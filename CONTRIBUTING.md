# Contributing

This repository contains a research paper and supporting documentation. It is not a software project.

## Feedback Welcome

- **Issues**: Corrections, reference suggestions, and clarifications are welcome via GitHub Issues.
- **Discussions**: Meta-level feedback or questions about the framework can be posted in GitHub Discussions if enabled.

## No Guarantee of Response

This is independent research maintained on a best-effort basis. There is no commitment to respond to issues or incorporate suggestions.

## Citation Corrections

If you notice an error in the citation metadata (CITATION.cff) or documentation, please open an issue with the correction.

## Not Accepting Pull Requests

The canonical paper artifact is fixed. Pull requests modifying the PDF or core claims will not be merged.

Documentation improvements (typos, formatting, broken links) may be considered.
