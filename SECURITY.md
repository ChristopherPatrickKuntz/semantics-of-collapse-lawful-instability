# Security Policy

## Scope

This repository contains a research paper and documentation. No executable code is shipped.

## Reporting Issues

If you believe there is a security-relevant error in the research claims or methodology, please open a GitHub Issue describing the concern.

Do not post sensitive information, private disclosures, or unverified claims publicly.

## Contact

For private correspondence, contact the author via the channels listed in the paper or GitHub profile.

## Responsible Disclosure

This is a research artifact, not production software. Standard vulnerability disclosure timelines do not apply. However, good-faith feedback on potential misuse scenarios or unintended implications is appreciated.
